# Interactive Sales Dashboard (Power BI)

This project is a part of Task 4: Dashboard Design, aimed at building an interactive business dashboard using the *Sample Superstore* dataset in *Power BI Desktop*.

## Objective
Design an interactive dashboard for business stakeholders to gain actionable insights from sales data.

## Tools Used
- Power BI Desktop
- Sample Superstore Dataset (from Kaggle)

## Key Features
- KPI Cards for Sales, Profit, Quantity, and Discount
- Dynamic filters and slicers (Region, Segment, Category, Sub-Category)
- Trend analysis through charts and bar graphs
- Profit margin insights with discount impact visualization
- Clean, consistent theme and layout

## Insights
- Identified top-performing categories and sub-categories
- Visualized regional profitability
- Highlighted trends in sales and discount effectiveness

## Outcome
An interactive dashboard that enables data-driven decisions by visualizing key sales metrics and performance indicators.
